STYLE GUIDE

이 페이지는 프론트 모바일 페이지에 사용되는 주요 UI 컴포넌트와 스타일을 보여줍니다.

  • 프론트 MO html 링크
  • Color Palette, Typography
  • Input, Button, Component
버튼 인풋 · 폼 배지 탭 리스트 에디터 내용 레이어 팝업
기준: 왼쪽 점선 박스는 모바일 폭(360px) 미리보기이고, 오른쪽은 사용 클래스와 규칙입니다. 버튼·입력 등 컴포넌트에는 margin 을 넣지 않고, 간격은 감싸는 영역에서 지정합니다.

버튼

기본 버튼 (40px)

  • .btn_primary : 파란 배경 버튼, disabled 시 회색
  • .btn_primary.line : 회색 테두리 (로그인, 회원가입 화면)
  • .btn_primary.outline : 파란 테두리 (나의 강의실, 게시판 목록 버튼)
  • button, a 모두 사용 가능, 높이는 모두 40px 로 통일 (팝업 닫기 .btn_full, 간편상담 신청 버튼도 40px)

작은 보조 버튼 (32px)

  • .btn_small : 높이 32px 흰 바탕 보조 버튼 (쪽지함, 전체 읽음 처리)

인풋 · 폼

입력 항목 기본 구조

실명이 아닌 경우 수강신청, 상담 등 제한이 있을 수 있습니다.

  • .input_area : 라벨 → 안내 → 입력칸 → 메시지 순서, 간격 8px
  • .field_label : 라벨 (16px), 필수 항목은 .essential 추가 시 빨간 * 표시
  • .info_message : 회색 안내 문구
  • 입력칸 높이 50px (게시판 글쓰기 .write_form 안에서는 40px)

오류 / 성공 상태

비밀번호가 일치하지 않습니다.

사용 가능한 아이디입니다.

  • 입력칸에 .error : 빨간 테두리
  • .error_message 빨강 / .success_message 파랑
  • 평소에는 메시지에 hidden, 상태에 따라 해제

입력값 삭제 버튼 / 중복확인

  • .input_clear 안에 input + .btn_clear : 값이 있을 때만 삭제 버튼 노출 (스크립트 연결됨)
  • .multiple : 한 줄에 여러 입력 (간격 8px), .btn_check 120px 파란 버튼

셀렉트 / 텍스트 영역

  • select : 공통 화살표 아이콘(ico_select_arrow.svg) 자동 적용
  • 다중 선택 드롭다운은 .custom_select (회원가입 정보입력 참고)

체크박스 / 라디오

  • 체크박스·라디오는 공통으로 24px 디자인 아이콘 적용 (common.css)
  • label.form_check 로 감싸면 글자 클릭 가능, 선택 시 글자 진하게
  • .check_group : 가로 나열 (간격 16px)
