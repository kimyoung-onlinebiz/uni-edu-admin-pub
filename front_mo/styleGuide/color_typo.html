폰트 · 글자 크기

폰트

  • Pretendard Variable (common.css @font-face, 웹폰트 내장)
  • 굵기는 font-weight 100 ~ 900 사용 가능, 주로 400 / 500 / 600 / 700 사용
  • 입력칸 글자는 16px 이상 (iOS 입력 시 화면 자동 확대 방지)

변수크기예시 (권장 굵기)용도

공통 클래스

모바일은 여백·정렬 유틸 클래스(marginT8 등) 없이 각 컴포넌트 CSS 에서 간격을 지정합니다. 버튼 간격도 버튼이 아닌 감싸는 영역에서 지정합니다.

클래스 / 속성설명
.blind화면에서는 숨기고 스크린리더로만 읽는 텍스트 (아이콘 버튼의 이름 등)
hidden 속성요소 숨김 (display:none !important) : 레이어 팝업 닫힘 상태, 로그인 전·후 영역 등
