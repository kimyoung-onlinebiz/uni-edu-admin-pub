  • 수강은 윈도우 운영체제를 사용하는 기기에서만 가능하며, 맥북을 사용하셔야 한다면 맥북에 윈도우를 설치하여 수강하시기 바랍니다.
    단, 맥북에 윈도우 설치로 인해 발생하는 오류에 대해서는 교육원에서 책임지지 않으며, 시험 응시는 윈도우 운영체제 PC에서만 가능한 점 참고 부탁드립니다.

    [Mac OS X 지원 안내]
    Mac OS X 환경에서도 맥 전용 콜러스 플레이어(Kollus Player)를 설치한 후 수강하실 수 있습니다.
    단, 맥 전용 콜러스 플레이어(Kollus Player)는 아래 환경에서만 설치 및 사용이 가능합니다.
    • Mac OS X 10.9 (매버릭스, Mavericks)
    • Mac OS X 10.10 (요세미티, Yosemite)
    • Mac OS X 10.11 (엘 캐피탄, El Capitan)
    맥 전용 콜러스 플레이어(Kollus Player) 설치 안내는 아래 링크를 참고해 주시기 바랍니다.
    http://info.kollus.com/mac

    주의
    • Parallels(패러렐즈), VMware 등의 가상 머신을 통해 Windows 운영체제에서 Kollus Player를 구동할 경우 정상적으로 실행되지 않을 수 있습니다.
    • Mac OS 단말기에서 Windows 운영체제로 Kollus Player를 사용해야 하는 경우, 가상 머신이 아닌 Boot Camp(부트캠프)를 통해 Windows를 멀티 부팅하여 사용하시기 바랍니다.
  • 답변 내용이 들어가는 영역입니다.

지원 불가 환경

  • [A] 아이패드 iOS 13 이상부터 데스크탑 모드가 적용되어 아이폰·아이패드가 모바일 기기가 아닌 PC로 인식되는 문제가 발생할 수 있습니다.
    아래 방법으로 설정을 변경해 주시기 바랍니다.

  • (Safari 브라우저 이용 권장)
    ※ 설정 > Safari > 데스크탑 웹 사이트 요청(또는 데스크탑 페이지 요청)이 켜져 있다면 [끄기(Off)]로 변경
    → Safari로 접속 후 수강 가능 여부 확인

    위 방법으로도 수강이 되지 않을 경우, 아래 방법으로 쿠키 및 방문 기록을 삭제한 후 다시 접속해 주시기 바랍니다.
    ※ 설정 > Safari > 방문 기록 및 웹 사이트 데이터 지우기 선택
    → 방문 기록 및 웹 사이트 데이터 삭제 진행 후 Safari 재접속 및 수강 가능 여부 확인
